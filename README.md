# NONLINEAR Raumfahrt – Website

Statische Website, kein Build nötig.

## Online stellen mit GitHub Pages
1. Neues öffentliches Repository anlegen, z. B. `nonlinear`.
2. Den Inhalt dieses Ordners hochladen (`index.html`, `og-image.jpg`, Ordner `img/`).
3. Settings → Pages → Source: „Deploy from a branch“, Branch `main`, Ordner `/ (root)`.
4. Nach ca. 1 Minute ist die Seite unter `https://<benutzername>.github.io/nonlinear/` erreichbar.

Alternative: Ordner per Drag & Drop auf https://app.netlify.com/drop ziehen.

Das 3D-Modell lädt three.js von cdn.jsdelivr.net, die Schriften kommen von Google Fonts.
